MOCHICA の箱でやること（これから順に作ります）

  1. MiiTel の録画・文字起こしを取り込んで議事録に → Salesforce に記録・新規商談の立ち上げ・ステージ更新

商談
読み込んでいます…
左の商談を選ぶと、ここに中身が出ます。

Bales に SF の情報を入れる

Bales のカスタム情報（失注商談失注日・失注理由 大/中/詳細/小・失注前ステージ・顧客の現状・利用中ATS・採用人数 など21項目）は、SF の「Mochica（リード）」の同じ名前の項目です。Bales の SalesforceID（00Q…）＝SF のリードの ID なので、SF のリードの値を、そのまま Bales に入れるファイルを作ります。

取り込み用ファイル（CSV）をダウンロード
「集計する」を押すと、SF のリードを読み込みます（1〜2分かかります）。

件数は SF の リードの数です（Bales に入っているのは約2.3万件）。Bales に無いリードの行は、取り込むときに当たらずに飛ばされます。いまは「ダウンロード → Bales でリードの更新として取り込み（SalesforceID で当てる）」の手作業です。Bales の取り込み（更新）の画面が分かりしだい、拡張機能で毎朝自動で取り込むようにします。

架電（Zoom Phone）準備中

インターン生の Zoom Phone の架電記録を、人ごと・日ごとに集めます（DOC の kincall で使っている Zoom Phone のつなぎ方を使い回します）。

アポ（カレンダー）準備中

カレンダーのアポを読み、獲得者・商談の予定を一覧にします（DOC のアポ履歴の仕組みを使い回します）。

DOC の議事録（見るだけ）

DOC の商談の議事録は、商談履歴で見られます（直したり、DOC の Salesforce に書いたりはしません）。
