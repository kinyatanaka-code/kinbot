DOCMOCHICA
読み込んでいます…

MOCHICA の箱でやること（これから順に作ります）

  1. MiiTel の録画・文字起こしを取り込んで議事録に → Salesforce に記録・新規商談の立ち上げ・ステージ更新
  2. インターン生の Zoom Phone の架電と、カレンダーのアポを集める
  3. Bales Cloud のリストを読む

DOC の kinbot（録画・kincall・kinXs）はそのまま動きます。MOCHICA の箱は、そこを触らずに横に作っています。

MOCHICA のメンバー

読み込んでいます…

メンバーの DOC／MOCHICA は、kinbot の設定 → メンバー管理の「プロダクト」で決めます。

商談（MiiTel）準備中

MiiTel の録画・文字起こしを取り込み、要約・分析を作って、Salesforce の「MOCHICA リード」から新規の商談を立ち上げ、ステージを進められるようにします。まず「設定（連携）」で MiiTel の API をつないでください。

リスト（Bales Cloud）準備中

Bales Cloud のリストを読み、会社・架電の状況を kinbot で見られるようにします。まず「設定（連携）」で Bales Cloud の API をつないでください。

架電（Zoom Phone）準備中

インターン生の Zoom Phone の架電記録を、人ごと・日ごとに集めます（DOC の kincall で使っている Zoom Phone のつなぎ方を使い回します）。

アポ（カレンダー）準備中

カレンダーのアポを読み、獲得者・商談の予定を一覧にします（DOC のアポ履歴の仕組みを使い回します）。

DOC の議事録（見るだけ）

DOC の商談の議事録は、商談履歴で見られます（直したり、DOC の Salesforce に書いたりはしません）。
