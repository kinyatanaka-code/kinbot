MiiTel の会議履歴を受け取る（Outgoing Webhook）

MiiTel Admin → 外部連携 → Outgoing Webhook → 「会議履歴」タブ → 連携設定を追加 で、次の2つを入れてください。送るタイミングは「会議履歴の音声分析完了時」と、使えれば「議事録作成完了時」「文字起こし要約完了時」も選びます。

追加ヘッダーは合言葉です。ほかの人に見せないでください。

MiiTel の文字起こし・議事録の読み込み

MiiTel には外から読む鍵（API）が無いので、営業担当それぞれの Chrome で読みます。パスワードは kinbot に入れません。

  1. 各自の Chrome に拡張機能 kinbot-ext（1.4.0 以上）を入れる（kinbot の設定 → 拡張機能）
  2. その Chrome で、自分の MiiTel のアカウントでログインしておく
  3. MiiTel で会議のページを開くと、その会議の文字起こし・議事録が自動で kinbot に入る。まとめて入れるときは「商談（MiiTel）」の「MiiTel から文字起こし・議事録を読む」
