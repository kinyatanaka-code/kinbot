登録リンク

よく使う会議リンク（Zoom / Meet / Teams）を名前付きで登録。レコーディング画面のプルダウンから選べます。
自分がいつも使う部屋には 「スマートリンクにする」 を押してください。
スマートリンクとは、担当者が決まる前に発行できるURLです。アポの案内メールにそのURLを貼って送っておけば、あとで担当が決まったとき（変わったとき）に、行き先が自動でその人の部屋に切り替わります。送ったメールを送り直す必要はありません。

    Zoom自動入室

    現在、カレンダーからの自動入室はオフになっています。商談の録音はレコーディング画面から手動でボットを入れてください。 以下の設定は保存されますが、自動入室は行われません。再開したい場合は、Railwayの環境変数に CALENDAR_AUTO_JOIN=1 を追加してください。

    登録したZoomのURLの会議が始まると、kinbotが自動で入室して録画を開始します。方法は2つあります。
    （1）カレンダー方式（おすすめ・Zoomアプリ不要）：Googleカレンダーにその会議の予定が入っていれば、開始時刻に自動入室します。各URLの「予定の時間に入室（URL照合なし）」にチェックを入れると、予定にURLを貼っていなくても、相手を招待した予定の開始時刻にその部屋へ入室します。
    （2）Zoom Webhook方式：会議開始を即時検知して入室します（下の手順でZoom連携が必要・上級者向け）。

        Claude Code などで分析する（APIトークン）

        発行済みのAPIトークンを使うと、Claude Code やターミナルから商談データを取得して分析できます。トークンは Railway の環境変数 API_TOKENS で発行します。よく使うトークンをここに貼っておくと、下のコード例に自動で差し込まれてコピーしやすくなります。

        ⚠️ トークンは全社員の商談データを読める鍵です。共有PCでは保存しないでください。保存先はこのブラウザ内のみ（サーバーには送信しません）。漏れた場合は Railway の API_TOKENS から削除すれば即失効します。

        1. ベースURL
        （このアプリのURL）
        2. 商談一覧を取得
        curl -H "Authorization: Bearer <トークン>" \
  /api/meetings
        3. 1商談の詳細（文字起こし・要約・分析）
        curl -H "Authorization: Bearer <トークン>" \
  /api/meetings/<bot_id>
        4. 新プロセスの抽出データ（案件・イベント）
        curl -H "Authorization: Bearer <トークン>" /api/deals
curl -H "Authorization: Bearer <トークン>" /api/deal-events
        Claude Code への指示例
        「/api/deal-events を Bearer トークン <トークン> で取得して、担当者ごとに『初回商談数・今月判断・来月判断・失注・再商談実施・受注』を集計して」

        ヘッダを付けにくいツールでは ?token=<トークン> をURL末尾に付けても認証できます。

        ChatGPTのGPTから会話する（Custom GPT）

        ChatGPTの「GPTを作成」で、kinbot専用のGPTを一度作っておけば、普段のChatGPT画面からそのGPTを開いて「森田さんの今月の商談状況は？」のように聞くだけで、GPTが自動でkinbotに問い合わせて答えます。※ GPT作成が使える ChatGPT Plus / Team / Enterprise のいずれかが必要です。

        作成手順

        ① スキーマのURL（「URLからインポート」に貼る）
        https://kinbot-production-225f.up.railway.app/gpt-actions-openapi.yaml
        ② APIトークン（認証の「APIキー」欄に貼る）
        kbt_7bcaf98705c30c3655a8b17dbbd85a0e359aba8b68e3f507

        ⚠️ このトークンは全社員分のデータを読める管理者トークンです。作ったGPTは必ず「自分のみ」か「リンクを知っている人（社内限定）」で共有し、社外に公開しないでください。人数が増える・退職者が出るなどのタイミングで、Railwayの API_TOKENS からこのトークンを見直してください。

              メンバー管理

              kinbotに関わる人をここで一括登録します。この内容がアポ振り分けの割り振り設定、アポ獲得者のカレンダー照合、実績のチーム別集計にそのまま使われます。ほかの画面で別に登録する必要はありません。

              クローザー　商談を担当します。アポ振り分けのローテーションに入ります。 インサイド　アポを獲得します。カレンダー照合の対象になります。 予備　通常の順番には入らず、他の全員が埋まっているときだけ回ります。

              インサイドのカレンダー照合には、各メンバーのGoogleカレンダーが下の「カレンダー照合の代表者」に指定した人へ共有されている必要があります（共有設定で「予定の詳細をすべて表示」）。社内カレンダーが全社共有になっていれば、そのままで読めます。

              アポ数の集計は インターンアポ、割り振りの設定は アポ振り分け から行えます。

              カレンダー照合の代表者

              インターン生のカレンダーを読むために使うGoogle連携を選びます。ここで指定した人の連携を経由して照合されるため、他のメンバーはGoogle未連携でも「カレンダーと照合」を実行でき、全員がアポ状況を見られます。候補には、Google連携済みの人だけが表示されます。

              商談予定の自動作成（招待方式）

              アポ振り分けで担当を割り当てると、商談予定を自動で作成します。作り方は2通りから選べます。

              担当者本人のカレンダーに作る…その担当者のGoogle連携を使って本人のカレンダーだけに作成します。運用者や他のメンバーのカレンダーには入りません。担当者がGoogle未連携の場合は、自動的に下の招待方式に切り替わります。
              運用者のカレンダーに作り、招待する…運用者のカレンダーに予定ができ、担当者はゲストとして招待されます。担当者がGoogle未連携でも使えますが、運用者のカレンダーにすべての商談が入ります。

              上の運用者は招待方式のときと、担当者が未連携のときの受け皿として使われます。カレンダーへの書き込みには、その人が 設定→連携→Google連携をやり直して権限を承認しておく必要があります。
