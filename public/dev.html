開発メモ

自動で直す（1時間ごと）

溜まった「直したいこと」を、1時間ごとにClaudeが直します。
小さくて安全な変更だけが本番に入り、少しでも引っかかるものはPR（確認待ち）になります。
おかしくなったら、まずここをOFFにしてください。戻すのは GitHub の Actions →「巻き戻し」です。

「本番に入れる」をOFFにすると、直したものは全部PRになります（人が見てからマージ）。
時間帯を「20〜8」のようにすると、商談中の時間には入らなくなります。

自己点検

kinbotが自分で、ライブ配信・プロセスシート・各連携・カレンダーの見張りを見に行きます。 おかしいところが見つかったら、直し方の案を作って知らせます。
知らせ先は、ここで指定した1か所だけです（DOC Teamなどチームの場所には送りません）。 点検は読むだけで、Salesforceは書き換えません。

Chatで自分だけのスペースを作り、そのWebhook URLを入れてください。空のままだと、画面で見るだけになります。

画面の使いやすさの見直し

kinbotが自分の画面を1つずつ見て、使いやすくする案を出します。 出た案は下の「直したいこと」に残るので、朝のまとめと夜の自動修正に乗ります。
知らせ先は、上の自己点検と同じ1か所だけです。

直したいこと・やりたいこと

気づいたときに、Google Chatで @kinbot 要望 〜 と送るだけで、ここに溜まります。
うまくいかなかった処理（SFの立ち上げ・カレンダーの取り込みなど）や、Chatで答えられなかった質問も、kinbotが自動で拾って残します。
朝6時に、まとめてGoogle Chatへ流します。

開発メモの朝のまとめは、既定でOFFです（毎朝の「kinbotが新しくなりました」に置き換えました）。
ONにすると、これまで通り朝6時にChatへ流れます。自己点検や画面の見直しの知らせも、この設定に従います。

前の営業日からの変更を、営業メンバーに分かる言葉でまとめて送ります（月曜は金曜からの3日ぶん）。土日は送りません。
