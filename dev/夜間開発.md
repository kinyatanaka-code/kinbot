# 夜間開発のしくみ（Claude Code）

田中さんが寝ている間に、kinbotに溜まった「直したいこと」をClaude Codeが直し、
朝にPR（変更の提案）が用意されている、という流れです。

## 一日の流れ

```
昼   気づいたらChatに一言   @kinbot 要望 メールの宛先を自動で入れてほしい
     kinbotが自動で拾う     SFの立ち上げ失敗・答えられなかった質問 など
                ↓
3:00 GitHub Actions が動く
     ① kinbotから「直したいこと」を読む
     ② 危ないものを外して、上位3件を選ぶ
     ③ Claude Code が直す
     ④ node --check と起動確認
     ⑤ PRを作る（mainには入れない）
     ⑥ 結果をGoogle Chatへ
                ↓
6:00 朝の開発メモがChatに届く
                ↓
朝   PRを見て、よければマージ → Railwayが自動でデプロイ
```

**mainには自動で入りません。** 必ず田中さんが目で見て、マージを押したときだけ反映されます。

## 用意するもの（1回だけ）

### 1. Anthropicのキー

console.anthropic.com → API Keys → 新しいキーを作る。

### 2. kinbotのトークン

適当な長い文字列を決めます（例：`kbt_night_xxxxxxxx`）。
Railwayのkinbotの環境変数に足します。

| 変数名 | 値 |
|---|---|
| `API_TOKENS` | `kbt_night_xxxxxxxx:admin` |

すでに `API_TOKENS` がある場合は、カンマで足してください。

### 3. GitHubに登録

リポジトリ → Settings → Secrets and variables → Actions

**Secrets（New repository secret）**

| 名前 | 値 |
|---|---|
| `ANTHROPIC_API_KEY` | 1で作ったキー |
| `KINBOT_TOKEN` | 2で決めた文字列（`:admin` は付けない） |

**Variables（任意）**

| 名前 | 値 |
|---|---|
| `KINBOT_URL` | `https://kinbot-production-225f.up.railway.app` |

### 4. PRを作れるようにする

リポジトリ → Settings → Actions → General → Workflow permissions

- **Read and write permissions** を選ぶ
- **Allow GitHub Actions to create and approve pull requests** にチェック

## 動かしてみる

Actions → 「夜間開発（Claude Code）」→ **Run workflow** で、その場で試せます。
`今夜やる件数` を 1 にして、まず1件だけ試すのがおすすめです。

## 安全のためにしていること

| こと | 内容 |
|---|---|
| mainに直接入れない | 必ずPRにする。人が見てからマージ |
| 危ないものは外す | Salesforceのコンバート、一括削除、料金、権限・鍵まわりは自動で触らない |
| 確かめてからPR | `node --check` と、実際にサーバーが起動するかを確認 |
| 決まりを渡す | `CLAUDE.md` に、書き方・やってはいけないことを明記 |
| 件数を絞る | 一晩に最大3件（変更できます） |
| 迷ったら止める | 自信が持てないものは手を付けず、理由をPRに書く |

## 費用の目安

1晩あたり数十円〜数百円ぐらい（直す量による）。
毎晩動かして月に数千円が目安です。`schedule` の行を消せば、手動のときだけ動きます。

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| PRができない | Settings → Actions の権限（上の4） |
| 「kinbotから読めませんでした」 | `KINBOT_TOKEN` と、Railwayの `API_TOKENS` が合っているか |
| 何も直らない | Actionsのログで `dev/NIGHT_BRIEF.md` の中身を確認 |
| 起動確認で落ちる | 変更に問題があったということ。PRは作られないので、そのままで安全 |
